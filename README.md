# ✈️ Travelin – Mobile Travel App UI Design

![Travelin Banner](Travel%20App.png)

## 📌 About the Design
**Travelin** is a modern mobile UI concept built to simplify and enrich the travel experience. From planning a trip to booking and discovering new destinations, the app offers a clean and intuitive design tailored for travelers. Created using **Figma**, this prototype focuses on smooth user onboarding, accessible search, and personalized recommendations.

---

## 🔹 Key Screens

### 🌍 Splash & Welcome Screens  
Bold branding with a travel quote and beautiful background to inspire wanderlust.

### 🔐 Sign In/Sign Up Screens  
User-friendly login with multiple sign-in options:  
- Google  
- Apple  
- Facebook

### 🧭 Home Dashboard  
Personalized greeting, upcoming trip summary, and quick access to travel information.

### 🗺️ Journey Together Section  
Featured destinations with ratings, pricing, and visual previews for inspiration.

### 🏨 Hotel Recommendations  
Curated hotel listings with:
- Star ratings  
- Location details  
- Starting price info  

### 📱 Navigation Bar  
Bottom tab bar for seamless browsing with the following sections:
- Home  
- Orders  
- Deals  
- Account

---

## 🎨 Design Highlights

- **Branding**: "Travelin" features a suitcase-themed “in” icon and a catchy tagline:  
  _"Your Passport to Seamless Adventures!"_

- **Color Palette**: Calming blues and white backgrounds represent trust, peace, and openness.

- **Typography**: Clean, modern fonts optimized for mobile readability.

- **UI Components**:  
  Rounded input fields, cards, and icons designed for a smooth and friendly interface.

- **Responsiveness**: Layouts optimized for mobile screen sizes, ensuring a consistent experience.
